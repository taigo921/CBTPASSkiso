# 全員向けランキングは取り消し（2026-10-16）

ユーザーの依頼で直前の管理者専用ランキングに戻した。参加チェックボックス・公開集計の配信・自動掲載を取り消し、問題集1/2の合計成績を管理者がusersから表示する従来方式に戻す。アクセス管理と本の進捗登録は維持する。

アプリの取り消しはPages配備で反映できる。一方、先に反映された全員向けFirestoreルールはこの環境から更新できないため、Firebase Consoleでこのブランチ/mainの最新firestore.rules全文を反映する必要がある。最新版はaccessControlとusersの既存制限を残し、廃止したleaderboardの取得・一覧・新規掲載・更新をすべて拒否する。残存集計の削除のみ本人・管理者に許可する。

古いアプリが端末に残っていても、ルールを戻せば共有集計の取得・再掲載を拒否できる。アプリの取り消し配備と、本番ルールの反映完了は区別する。学習記録や既存のアクセス停止設定を自動削除しない。
